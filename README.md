# org-accessibility-docs

Repositório de documentação de acessibilidade da organização, organizado em Markdown.

## Estrutura

```
org-accessibility-docs/
├── checklists/          # Listas de verificação de acessibilidade
│   ├── web.md           # Checklist para interfaces Web (WCAG 2.2)
│   ├── mobile.md        # Checklist para aplicativos Mobile (iOS e Android)
│   └── design.md        # Checklist para designers (cores, tipografia, layout)
├── guidelines/          # Regras específicas da marca
│   └── color-contrast.md  # Contraste de cores da marca com tabelas de aprovação/reprovação
└── standards/           # Padrões e critérios de referência
    └── wcag-2.2.md      # Critérios de sucesso do WCAG 2.2 (todos os níveis A e AA)
```

## Conteúdo

### `checklists/`

Listas de verificação práticas para garantir acessibilidade em diferentes contextos:

- **[web.md](checklists/web.md)** – Verificação para interfaces web: imagens, contraste, navegação por teclado, formulários e mais.
- **[mobile.md](checklists/mobile.md)** – Verificação para apps iOS e Android: rótulos acessíveis, tamanho de toque, leitores de tela (VoiceOver / TalkBack).
- **[design.md](checklists/design.md)** – Verificação para designers: contraste, tipografia, layout, estados de foco e entrega para desenvolvimento.

### `guidelines/`

Regras específicas da marca que complementam os padrões internacionais:

- **[color-contrast.md](guidelines/color-contrast.md)** – Paleta de cores da marca com proporções de contraste verificadas, regras de uso em botões, links e mensagens de status.

### `standards/`

Cópias e resumos dos critérios de referência internacionais:

- **[wcag-2.2.md](standards/wcag-2.2.md)** – Todos os critérios de sucesso do WCAG 2.2 (níveis A e AA), incluindo as novidades em relação ao WCAG 2.1.

## Meta de Conformidade

Nossa organização tem como meta atingir o nível **AA do WCAG 2.2** em todos os produtos digitais.
